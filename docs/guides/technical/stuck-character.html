Stuck Character

Fix frozen characters, ragdoll bugs, and falling through the map.

Occasionally your character may freeze, get stuck in an animation, or fall through the map. These are usually client-side issues you can fix without staff.

Try /fixme first

1

Use /fixme

Type /fixme in chat. This resets your character position and state. Wait a few seconds after using it before you move again.

If /fixme doesn't work

2

Reconnect

Disconnect from the server and join again. Your character data is saved. You will not lose progress.
3

Clear cache

A fall-through or loading issue that keeps happening may need a cache clear before you reconnect.
Don't abuse /fixme
Using /fixme to escape active roleplay, such as mid-arrest or mid-scene, is a rule break. Only use it for a genuine technical bug.
Still stuck?
If you still cannot play after reconnecting, open a ticket in Discord with a short description and a clip if you have one.
