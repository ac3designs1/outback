Enable Pure Mode

Skip the FiveM restart when connecting to a protected server.

Some FiveM servers require pure mode on your client. Without it, FiveM may close and restart before you can join. Setting pure mode on launch avoids that restart.

Windows shortcut method

1

Open FiveM properties

Find your FiveM shortcut on the desktop or in the Start menu, right-click it, and select Properties.
2

Edit the target field

Click the Target field. After FiveM.exe, add a space and type -pure_1. Example: C:\Users\You\AppData\Local\FiveM\FiveM.exe -pure_1
3

Apply and launch

Click Apply, then OK. Launch FiveM from this shortcut from now on.
What pure mode does
Pure mode restricts modified game files on your client so anti-cheat can run. Only use the launch flag if you understand it. Most players on a roleplay server benefit from starting with pure mode enabled.
