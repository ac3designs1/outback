Clear FiveM Cache

Fix crashes, slow loading, and corrupted client data.

Clearing your FiveM cache removes downloaded server assets and temporary files. This often fixes crashes on join, stuck loading screens, and missing map objects.

Close FiveM first
Fully close the FiveM client before clearing cache. Do not delete files while FiveM is running.

Steps (Windows)

1

Open the FiveM data folder

Press Win + R, type %localappdata%\FiveM\FiveM.app\data, and press Enter.
2

Delete cache folders

Delete cache, server-cache, and server-cache-priv if they exist. Do not delete the entire data folder. Only these cache directories.
3

Relaunch FiveM

Start FiveM again and reconnect to OutbackRP. The first join after clearing cache may take longer while assets download again.

When to clear cache

  • FiveM crashes when joining, or after a server update
  • Stuck on a loading screen
  • Missing buildings, props, or map objects
  • Menus behaving incorrectly after an update
