How server access and whitelisted departments work.

Server access

OutbackRP is allowlisted. Join discord.gg/outbackrp, read the rules, and complete verification. That verification is what grants you access to connect.

Departments

Police and EMS are whitelisted. Applications are posted in the OutbackRP Discord. Mechanic work and civilian jobs are open once you're in the city.
